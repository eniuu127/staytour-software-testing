# Test Cases – STAYTOUR

## 1. Giới thiệu

Thư mục `01-Test-Cases` lưu trữ các trường hợp kiểm thử cho **Hệ thống đặt Homestay và Tour du lịch (StayTour)**. Test Case được thiết kế nhằm đánh giá các chức năng chính và một số yêu cầu bảo mật cơ bản.

## 2. Nội dung kiểm thử

| Sheet | Nội dung | Số Test Case |
|---|---|---:|
| Functional Test Case | Tìm kiếm, tài khoản, đặt homestay/tour, thanh toán, đơn hàng và quản trị | 50 |
| Security Test Case | Xác thực, bảo vệ dữ liệu, phân quyền và giao dịch | 10 |
| **Tổng** | | **60** |

## 3. Kết quả ghi nhận

| Trạng thái | Số lượng |
|---|---:|
| Pass | 53 |
| Fail | 6 |
| Not Tested | 1 |
| **Tổng** | **60** |

Tài liệu bao gồm các trường hợp kiểm thử, dữ liệu đầu vào, các bước thực hiện, kết quả mong đợi và kết quả thực tế. Đây là kết quả ghi nhận trong quá trình thực hành; các bài kiểm thử bảo mật được thực hiện ở mức cơ bản.
