# Test Cases – STAYTOUR

## 1. Giới thiệu

Thư mục `01-Test-Cases` lưu trữ bộ trường hợp kiểm thử của **Hệ thống đặt Homestay và Tour du lịch – StayTour** (08/2026 – 10/2026).

Bộ Test Case được xây dựng dựa trên yêu cầu và luồng hoạt động của website, phục vụ kiểm tra các chức năng chính và một số tình huống bảo mật cơ bản.

## 2. Nội dung kiểm thử

| Nhóm | Nội dung | Số Test Case |
|---|---|---:|
| Functional Testing | Đăng ký, đăng nhập, tìm kiếm, đặt homestay, đặt tour, thanh toán và các nghiệp vụ liên quan | 50 |
| Basic Security Testing | Các trường hợp kiểm tra bảo mật cơ bản của website | 10 |
| **Tổng** | | **60** |

**Công cụ sử dụng:** Excel để quản lý Test Case; Postman để kiểm tra API; Chrome DevTools hỗ trợ kiểm tra hoạt động website.

## 3. Kết quả kiểm thử

| Trạng thái | Số lượng |
|---|---:|
| Pass | 53 |
| Fail | 6 |
| Not Tested | 1 |
| **Tổng** | **60** |

Kết quả thực tế được đối chiếu với kết quả mong đợi, làm cơ sở ghi nhận lỗi và đánh giá kết quả kiểm thử. Các bài kiểm thử bảo mật được thực hiện ở mức cơ bản.
